# 从能运行，到能解释：VibeCalendar学习路径

面向掌握变量、函数和基础HTML的读者。目标是广泛认识一个桌面项目的组成，先理解一条完整流程，再接触不同技术方法；不要求先学习框架、打包器或设计模式全集。应用功能保持不变，实验不进入安装包。

先执行 `npm ci` 安装锁定依赖，再执行 `npm start` 观察应用。运行实验只需Node.js，不访问网络、不改写用户偏好，也不启动安装器。

| 顺序 | 本课只增加的主要概念 | 阅读与练习 | 完成标志 |
| --- | --- | --- | --- |
| 1 | DOM、事件、职责 | [页面入口](01-page.md) | 追踪一次下一月点击 |
| 2 | 纯函数、日期边界、断言 | [日期函数](02-functions.md) | 解释为何不修改输入Date |
| 3 | 动作、不可变更新、重放 | [状态转换](03-state.md) | 重放动作得到同一结果 |
| 4 | 数据契约、适配器、数组管道 | [外部数据](04-data.md) | 将两种字段整理为统一记录 |
| 5 | Promise、依赖注入、缓存 | [异步服务](05-async.md) | 解释两次调用为什么只发三个地址请求 |
| 6 | 进程边界、订阅、生命周期 | [桌面能力](06-desktop.md) | 解释取消订阅需要哪个函数引用 |
| 7 | 测试分层、生成器 | [验证与扩展方法](07-testing.md) | 区分行为测试与实现细节 |
| 8 | 配置、产物、发布 | [工程交付](08-delivery.md) | 区分验证、构建和发布 |

```sh
npm run learn          # 顺序执行六个带断言的离线实验
npm run learn -- 03    # 只执行数据适配实验
npm run verify         # 语法检查和自动化测试（含教学实验）
```

每课按“先观察 → 阅读入口 → 动手修改 → 回答问题”推进。编号01—06是实验编号，章节01—08是阅读编号，具体对应关系写在各课中。每个实验的原始版本都包含可运行断言；修改练习时先预测输出，运行后比较，再恢复基线。

生产代码采用浏览器全局导出与CommonJS双入口，使同一逻辑能在网页和Node测试中运行；实验用原生ES模块展示另一种模块方式。这是两种环境的边界选择，不需要把全部代码迁移成同一种形式。

遇到细节先查[代码导读](../CODE_WALKTHROUGH.md)，再查[架构约束](../ARCHITECTURE.md)。阅读注释时重点回答：输入是什么、返回什么、改变了什么、失败如何处理、为什么这样分层。
