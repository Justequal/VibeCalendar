# 4 · 在边界统一数据

前置：[状态转换](03-state.md)。阅读[holiday-data.js](../../src/renderer/holiday-data.js)的类型注释与两个`normalize*Data`函数。

网络JSON解析成功只代表语法可读，不代表日期、年份、名称或布尔值正确。Nate使用`isOffDay`，Timor使用`holiday`；适配器将两者变成日期键索引的`{name, isHoliday}`。之后统一补充`holiday`（假期类别）和`festival`（节日本日），界面无需了解提供方字段。

`map`转换每条记录，`filter`筛掉无效项，`Object.fromEntries`构造索引。外层结构错误或完全没有有效远端记录会抛错，服务层决定降级；持久化缓存校验更严格，损坏条目整体作废。冻结记录和映射防止共享数据被意外改写，也使渲染器可以比较快照引用。

运行 `npm run learn -- 03`，阅读[数据实验](../../lessons/03-data.mjs)。练习：在有效记录旁加入错误日期，观察错误记录被过滤；再删除唯一有效记录，观察断言捕获异常。

检查理解：新增提供方时为什么优先新增适配器，而不是修改每个日期格？统一契约让变化停留在数据边界。下一课连接网络与缓存。
